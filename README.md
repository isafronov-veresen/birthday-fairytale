# Ніч загаданих бажань · 28–29 (Для Каті · Кропивницький)

Інтерактивний казковий сайт-запрошення на день народження для **Каті** у Кропивницькому:

- **3D-конверт із сургучною печаткою** та звуками арфи (Web Audio API)
- **Секретна глава `28 числа 15:00 — 29 числа 11:00`**:
  - інтерактивна золота фольга-натяк, яку можна стерти пальцем;
  - вибір **аромату для таємного сюрпризу**: **Лаванда**, **Хвоя**, **Фрукти** або **Ягоди**.
- **Симетричне віяло карток-натяків (Таро)** із 3D-відкриттям у центрі екрану:
  - **Обід (5 закладів):** Малахіка, ЦКТ, Pecorini, Ресторація Кропивницьких, ChaCha
  - **День:** Гончарний майстер-клас vs Ковзанка (коньки)
  - **Пригода:** Кінна прогулянка vs Катання на квадроциклах
  - **Вечеря (5 закладів):** ЦКТ, Veranda, Fermento, Drova, Панорама *(ЦКТ автоматично прибирається з вечері, якщо обраний на обід)*
- **Автоматична доставка вибору в Telegram-бот** + експорт фінальної листівки у PNG та копіювання маршруту
- **Режим організатора** у футері для швидкого підключення Telegram-бота (з автопошуком Chat ID та тестовим повідомленням) і генерації персонального посилання для Каті

## Деплой на Vercel (рекомендовано для чистого посилання без токена)

1. Імпортуйте репозиторій на Vercel (кнопка **Deploy**).
2. Додайте змінні середовища (**Environment Variables**):
   - `TG_BOT_TOKEN` — токен вашого Telegram-бота від `@BotFather`
   - `TG_CHAT_ID` — ваш Telegram Chat ID
3. Зробіть Redeploy — ендпоінт `/api/telegram` ([api/telegram.js](api/telegram.js)) автоматично прийматиме фінальний вибір Каті та надсилатиме його вам у Telegram.

# Ніч загаданих бажань · 28–29 (Кропивницький)

Інтерактивний казковий сайт-запрошення на день народження:

- **3D-конверт із сургучною печаткою** та звуками арфи (Web Audio API)
- **Секретна глава `28 числа 15:00 — 29 числа 11:00`** із золотою фольгою, яку можна стерти пальцем
- **Віяло карток Таро-натяків** із 3D-відкриттям у центрі екрану:
  - **Обід** — 22 актуальні ресторани Кропивницького з перетасовкою колоди та повною книгою закладів
  - **День** — Гончарний майстер-клас vs Ковзанка (коньки)
  - **Пригода** — Кінна прогулянка vs Катання на квадроциклах
  - **Вечеря** — романтична добірка закладів Кропивницького (без дублю обіду)
- **Фінальна листівка-сузір’я** з експортом у PNG, копіюванням тексту та надсиланням у Telegram
- **Режим організатора** у футері для персоналізації імені, натяків і списку закладів

## Деплой на Vercel

Проєкт повністю статичний (`index.html` + `vercel.json`) — готовий до деплою в 1 клік без збірки.
